# 📧 Email Spam Classifier  

An end-to-end **Machine Learning project** that classifies emails as **Spam** or **Ham (Not Spam)** with high precision.  
Deployed as an interactive web app using **Streamlit** and **Render**.  

---

## 🚀 Goal  
To build and deploy an ML model capable of detecting spam emails with high accuracy and precision.  

---

## 📊 Dataset  
- Source: [Kaggle Email Spam Dataset](https://www.kaggle.com/)  
- Size: **5,000 labeled emails**  
  - 4,000 Ham  
  - 1,000 Spam  

---

## ⚙️ Process  
1. **Data Preprocessing**  
   - Tokenization  
   - Stopword Removal  
   - Vectorization using **TfidfVectorizer**  

2. **Model Training**  
   - Applied ML algorithms for classification  
   - Achieved **98% Accuracy** and **99% Precision**  

3. **Deployment**  
   - Built an interactive UI with **Streamlit**  
   - Deployed on **Render** for public access  

---

## 🛠️ Tech Stack  
- **Python**  
- **NLTK** – Text preprocessing  
- **scikit-learn** – ML modeling & evaluation  
- **TfidfVectorizer** – Feature extraction  
- **Streamlit** – Web app frontend  
- **Render** – Deployment
